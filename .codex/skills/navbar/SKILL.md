# Navbar Skills

Use this skill when creating or updating a navbar.

## Workflow

1. Inspect the existing project structure.

2. Review the provided design or design source.

3. Reuse the project's existing styling approach.

4. Create a reusable Navbar component.

5. Make the navbar responsive.

6. Make the navigation accessible.

7. Reuse existing UI components when possible.

8. Test desktop and mobile behavior.

9. Run project checks after implementation.
